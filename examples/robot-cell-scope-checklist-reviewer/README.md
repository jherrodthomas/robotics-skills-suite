# Example — `robot-cell-scope-checklist-reviewer.skill`

**What this skill produces:** A completed confirmation-review checklist over any Robot Cell Scope and Boundary workbook, with auto-filled findings, evidence references, recommended actions and a visual dashboard. Verifies boundary and space definitions, robot/peripheral inventory completeness, operational-mode coverage, that intended use and foreseeable misuse are stated rather than implied, and the stakeholder responsibility split — against ISO 10218-2:2025 and ANSI/A3 R15.06-2025. Never modifies the source workbook.

**Typical input shape:** Path to a cell-scope workbook xlsx (ideally a `robot-cell-scope-builder` output; best-effort on any equivalent boundary document) plus an output path for the checklist.

**Expected output:** 7-tab checklist xlsx — Title, General Info, Guide (FC/LC/PC/NO/NA legend), Summary dashboard with KPI tiles and charts, Confirmation Review (doc quality), Technical Assessment (ISO 10218-2:2025 substantive checks), Verification Assessment. Edition findings are raised for any workbook still citing ISO 10218-2:2011, ANSI/RIA R15.06-2012, or *safety-rated monitored stop* in place of *monitored standstill*.
