# Example — `urdf-model-spec-checklist-reviewer.skill`

**What this skill produces:** A findings checklist over any URDF/xacro model specification workbook — distro-baseline checks (is a ROS 2 distro named, and is it still supported at the target ship date), the URDF/xacro-versus-SDFormat boundary, kinematic-chain validity, inertial plausibility, joint-limit and `<safety_controller>` coverage, collision-versus-visual separation, mesh resolvability and unit scaling, `ros2_control` interfaces and transmissions, and REP-103 / REP-105 conformance. Does not modify the source workbook.

**Typical input shape:** A path to a URDF/xacro model specification xlsx (optimal on `urdf-model-spec-builder` output, best-effort on others), plus optional reviewer metadata and the spec's target ship date — the distro-support check is date-conditional.

**Expected output:** `<source>_checklist.xlsx` — Title and Summary roll-up tabs, a Findings list, and one tab per check category. Two findings are raised ahead of all others: **no distro named** (most downstream checks are distro-conditional and cannot run), and **identical detailed meshes used for both collision and visual** (the highest-yield defect in the checklist).
