# Example — `ot-asset-inventory-checklist-reviewer.skill`

**What this skill produces:** A confirmation-measures checklist auditing an OT Asset Inventory workbook against IEC 62443-2-1 and IEC 62443-3-2 — 24 checks split across Inventory Completeness (asset category and device-count coverage of the System under Consideration), Data Quality & Accuracy (network addresses, firmware versions, VLAN/zone assignment, ownership), and Risk & Lifecycle (criticality, patch status, end-of-support tracking).

**Typical input shape:** The path to an OT asset inventory xlsx (typically produced by `ot-asset-inventory-builder`), plus reviewer name and review date. Does not modify the source inventory.

**Expected output:** Checklist xlsx (5 tabs): Title, Summary (FC/LC/PC/NO/NA/PENDING roll-up and findings list), Inventory Completeness (IC1–IC8), Data Quality & Accuracy (DQ1–DQ8), Risk & Lifecycle (RL1–RL8). Each check is rated FC/LC/PC/NO/NA with a recommended action for PC and NO rows.
