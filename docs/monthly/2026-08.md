## Standards-edition watch

**The headline finding this month is a reversal, and it is against this task's own reference table.**

### ISO 3691-4 — the July defect was a false positive, and the "fix" introduced a real one

The June and July reports both flagged `iso3691-4-risk-assessment-builder` as carrying a superseded edition, on the grounds that its description reads **ISO 3691-4:2023** while this task's standing reference table calls the current edition **:2020**. Issue `#29` was opened against it.

**The reference table is wrong.** ISO 3691-4:**2023** (Edition 2, published June 2023, ISO cat. 83545) supersedes ISO 3691-4:2020, and **:2020 is withdrawn**. This was independently verified against iso.org this run, and the 2026-08-31 PLAN run reached the same conclusion by the same route. `iso3691-4-risk-assessment-builder` has been correct all along.

The consequence is worse than a wasted flag. Four skills currently pin the **withdrawn** :2020 edition:

Commit `a84987a` ("reconcile fleet-manager reviewer with builder, pin ISO 3691-4:2020") **reconciled a correct pair onto a withdrawn edition**, because it reconciled against the stale reference table rather than against ISO. `fleet-manager-architecture-builder` additionally carries a governing-standards table asserting Edition 2020, which is a stronger and more misleading claim than a bare mention.

**This is a self-inflicted regression and it is the repo's only substantive content defect.** It is also a warning about the shape of this whole task: a reference table that is wrong turns an autonomous correction loop into an autonomous *corruption* loop, and it did, once, this month.

### One class the audit cannot see

The 08-27 `tf-tree-spec` run and the 09-01 `nav2-config` run both found defects that **every edition check in this repo would pass**: a pair citing REP-105 correctly by number while describing a `world` frame REP-105 does not define, and a builder pinned to `ROS 2 Iron`, a real version string that has been **end-of-life since November 2024**.
