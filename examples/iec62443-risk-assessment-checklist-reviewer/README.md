# Example — `iec62443-risk-assessment-checklist-reviewer.skill`

**What this skill produces:** A confirmation-measures checklist over any IEC 62443 Risk Assessment xlsx and produce an audit-ready checklist with auto-filled findings, evidence references, and recommended actions for SL-T appropriateness and countermeasure adequacy. Probes the source risk assessment workbook, runs 25 standard checks split across Scope and Asset Completeness (coverage of all in-scope systems), Risk Analysis Rigor (threat and vulnerability identification), and Target SL Justification (SL-T alignment with consequence and likelihood). Auto-fills FC, LC, PC, NO, or NA and drafts findings for subjective items. Does not modify the source assessment. Emitted as a 7-tab workbook with a visual dashboard. Does not modify the source workbook.

**Typical input shape:** A path to a IEC 62443 Risk Assessment xlsx (optimal on `iec62443-risk-assessment-builder` output, best-effort on others), plus optional reviewer metadata (reviewer name, review date, project ID).

**Expected output:** `<source>_checklist.xlsx` — Title and Summary roll-up tabs, a Findings list, and one tab per check category.
