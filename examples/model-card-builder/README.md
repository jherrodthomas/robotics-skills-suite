**What this skill produces:** An audit-ready Model Card workbook following the model cards framework (Mitchell et al. 2019) for an ML perception, planning, or control model deployed on a robot — model details, intended use cases, operating factors and demographic groups, evaluation metrics, evaluation/training data, quantitative analyses across slices, fairness assessment, ethical considerations, and caveats. Aligned with current AI-governance frameworks (`ISO/IEC 42001:2023`, NIST AI RMF, EU AI Act).

**Expected output:** Multi-tab xlsx: title page, model details, intended use, factors, metrics, evaluation data, training data, quantitative slice analyses, fairness assessment, ethical considerations, caveats and recommendations.
