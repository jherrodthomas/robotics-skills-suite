# Example — `dataset-documentation-builder.skill`

**What this skill produces:** An 11-tab Datasheet-for-Datasets workbook for a robotics perception training dataset — motivation, composition with class distribution and split fingerprint, collection process with sensor rig / calibration state / operating-envelope coverage, preprocessing, recommended and out-of-scope uses, licensing, maintenance plan, and known biases framed as risk items.

**Typical input shape:** A JSON file carrying the dataset ID and semantic version, project and approver metadata, governance posture (EU AI Act high-risk or not), modalities and target domain, sample counts per class, split ratios, sensor and annotation protocol details, and the known-bias list.

**Expected output:** `<dataset>.xlsx` with the Title Page carrying the `<dataset-id>@<version>` citation string that `model-card-builder` records on its Training Data and Evaluation Data tabs.

**Sample I/O:** See `sample_input_robot_dataset.json` and `sample_dataset_doc.xlsx` (to be added).
