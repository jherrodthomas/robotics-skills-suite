# Example — `operator-training-matrix-checklist-reviewer.skill`

**What this skill produces:** Review and audit any Operator Training Matrix workbook for an industrial robot cell and produce a findings checklist. Checks that operator, programmer/teacher, maintenance and integrator roles are kept distinct with duty boundaries per ISO 10218-2:2025 and ANSI/A3 R15.06-2025; that OSHA 29 CFR 1910.147(c)(7) authorized / affected / other status is recorded by name as an attribute separate from role and agrees with the loto-procedure roster; that every requirement row separates training delivered from competency demonstrated with an evidence type and reference; that retraining triggers are stated as conditions per 1910.147(c)(7)(iii) and not as a bare interval; that certification carries employee name and dates per (c)(7)(iv) with retention and a re-qualification path; and that superseded editions (R15.06-2012, ISO 10218-2:2011) are not cited. Does not modify the source workbook.

**Typical input shape:** A path to a Operator Training Matrix xlsx (optimal on `operator-training-matrix-builder` output, best-effort on others), plus optional reviewer metadata (reviewer name, review date, project ID).

**Expected output:** `<source>_checklist.xlsx` — Title and Summary roll-up tabs, a Findings list, and one tab per check category.
