### The five are worse than "copy-pasted"

Reading the pairs side by side shows these descriptions were not hand-written and not merely
copied — they were **machine-derived from the builder by substituting the literal string `when`
with `to review`**, and the substitution broke the grammar in all five:

- `ansi-r1506` — "Use this skill **to review** the user mentions ANSI R1506…"
- `iec62061-sil` — "Use this skill **to review** the user mentions IEC 62061…"
- `iso10218-compliance-matrix` — "Use this skill **to review** the user mentions ISO 10218…"
- `iso12100-risk-assessment` — "Use this skill **to reviewever** the user mentions ISO 12100…"
- `iso13849-plr` — "Use this skill **to review** the user mentions ISO 13849…"

The `to reviewever` in `iso12100` is the smoking gun: the builder said "whenever", the replace hit
the embedded `when`, and nobody read the output. Every one of the five opens "Generate an
audit-ready … workbook", so each of these five reviewers advertises itself as a builder and its
trigger clause is not a sentence.

### Four of the five also carry a stale standard edition

This is the part that matters more than the grammar. The builders were edition-anchored by
earlier polish passes; the reviewer descriptions were not brought along.

| Pair | Builder cites | Reviewer cites | Severity |
|---|---|---|---|
| `ansi-r1506-compliance-matrix` | ANSI/A3 R15.06-**2025** (noting it supersedes 2012 (R2017)) | ANSI/RIA R15.06 **2012 R2017** | **high** — names the superseded edition as if current |
| `iec62061-sil` | IEC 62061:**2021**, "safety-related control systems (SCS)" | IEC 62061 (no year), "safety-related **electrical** control systems" | **med** — SRECS is the pre-2021 term IEC 62061:2021 retired |
| `iso13849-plr` | ISO 13849-1:**2023** | ISO 13849-1 (no year) | med |
| `iso12100-risk-assessment` | ISO 12100:**2010** (Clauses 5–6) | ISO 12100 (no year) | low — no newer edition to be wrong about |
| `iso10218-compliance-matrix` | ISO 10218-1/-2:2025 | ISO 10218-1/-2:2025 | ✅ edition correct; grammar defect only |

`ansi-r1506-compliance-matrix-checklist-reviewer` is the one to fix first. A reviewer whose
description names ANSI/RIA R15.06-2012 (R2017) will be selected for, and implicitly vouch for,
compliance work against a standard that the 2025 A3 adoption superseded. Its own builder
already carries the correction, sitting one file away.
