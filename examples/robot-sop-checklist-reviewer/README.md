# Example — `robot-sop-checklist-reviewer.skill`

**What this skill produces:** A completed review checklist over an existing Robot SOP workbook — findings, evidence references, and recommended actions rated FC / LC / PC / NO / NA, with a roll-up summary. Does not modify the source SOP.

**Typical input shape:** A path to a Robot SOP xlsx (optimal on `robot-sop-builder` output, best-effort on others), plus optional reviewer metadata (reviewer name, date, SOP revision under review).

**Expected output:** Multi-tab xlsx review checklist with a dashboard, checks grouped against the source SOP's 10 tabs, and a summary block. Low-confidence items are drafted as findings for human review rather than auto-rated.

**Sample I/O:** See `sample_workbook.xlsx` and `sample_checklist.xlsx` (to be added).
