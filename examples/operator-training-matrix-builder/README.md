# Example — `operator-training-matrix-builder.skill`

**What this skill produces:** A 9-tab audit-ready xlsx workbook. Generate an audit-ready Operator Training Matrix workbook for an industrial robot cell. Keeps the roles ISO 10218-2:2025 assigns different duties to distinct — operator, robot programmer/teacher, maintenance technician, integrator/commissioning — and carries OSHA 29 CFR 1910.147(c)(7) authorized / affected / other employee status as a separate attribute on every person, because this matrix is where the loto-procedure and robot-sop workbooks hand their training obligation. Every row separates training delivered from competency demonstrated with an evidence type; retraining is driven by stated conditions (job change, new hazard, procedure change, observed deviation, interval), not a bare interval; certification carries name and dates per 1910.147(c)(7)(iv). Anchored on ISO 10218-2:2025, ANSI/A3 R15.06-2025 (Parts 1-3) and ANSI/ASSP Z490.1-2024.

**Typical input shape:** Project and item data supplied in chat or as a JSON/xlsx handoff from the upstream skill in the chain (see the `## Related skills` section of the skill body).

**Expected output:** A multi-tab xlsx workbook, reviewable by the paired `operator-training-matrix-checklist-reviewer`.
