# robot-acceptance-protocol-builder — example

- **What this skill produces:** an 11-tab FAT/SAT acceptance protocol workbook with performance-acceptance criteria, safety-function validation, electrical commissioning checks, and a terminal customer sign-off block.
- **Typical input shape:** cell and robot identification, application description, contractual acceptance criteria, and the safety functions to be validated at FAT then re-validated at SAT.
- **Expected output:** xlsx acceptance protocol anchored on ISO 10218-2:2025 (cell integration) and ISO 9283:1998 (pose accuracy/repeatability, path accuracy, cycle time), with FAT gates sequenced ahead of SAT planning.
