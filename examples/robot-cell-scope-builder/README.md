# Example — `robot-cell-scope-builder.skill`

**What this skill produces:** An audit-ready Robot Cell Scope and Boundary workbook — the foundation artifact that fixes what is inside the cell, what is outside it, and who owns each part. Covers the physical boundary (footprint, safeguarded / restricted / operating space), robot and end-effector inventory, peripheral and safeguarding-device inventory, the operational mode matrix, intended use, the reasonably foreseeable misuse register, the stakeholder responsibility split, interfaces to adjacent cells and plant services, and assumptions/exclusions. Anchored on ISO 10218-2:2025 and its US national adoption ANSI/A3 R15.06-2025, with ISO 12100:2010 as the source of the intended-use / foreseeable-misuse construct.

**Typical input shape:** JSON object with project metadata (site, cell ID, integrator, end user, program phase); a boundary block describing footprint and the safeguarded / restricted / operating spaces; arrays for robots, end effectors, peripherals and safeguarding devices; the operational modes in use (automatic, manual reduced speed, manual high speed, teach, maintenance) and who may be present in each; free-text intended use; a list of foreseeable-misuse scenarios; and a stakeholder table assigning the integrator / user / supplier responsibility boundary.

**Expected output:** Multi-tab xlsx covering title page and document control, cell identification, physical boundary and space definitions, robot inventory, end-effector and peripheral inventory, safeguarding-device inventory, operational mode matrix, intended use statement, foreseeable misuse register, stakeholder and responsibility matrix, interfaces, assumptions and exclusions, and downstream hand-off references (to `iso12100-risk-assessment-builder` and `robot-cell-layout-builder`).
