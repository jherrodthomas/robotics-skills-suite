# Example — `robot-sop-builder.skill`

**What this skill produces:** An audit-ready Standard Operating Procedure workbook for an industrial robot cell — pre-start checks, startup sequence, normal operation, fault recovery, planned stop, emergency response, shutdown, PPE requirements, a responsibility matrix, and an operator training sign-off block. Anchored on ANSI/A3 R15.06-3-2025 (use of industrial robot cells), ISO 10218-2:2025, OSHA 29 CFR 1910.147 (LOTO) and 1910.132 (PPE).

**Typical input shape:** JSON object naming the cell and document metadata, the robots and major equipment in the cell, the operating modes and who may be present in each, an ordered step list per procedure (start / run / stop / recover / shutdown) with a responsible role and PPE per step, the LOTO procedure reference for energy-isolation steps, and the roles requiring training sign-off.

**Expected output:** Multi-tab xlsx (10 tabs): Pre-Start Checks, Startup Sequence, Normal Operation, Fault Recovery, Planned Stop, Emergency Response, Shutdown, PPE Requirements, Responsibility Matrix, Training Sign-Off.
